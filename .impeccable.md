# Design Context — Mastermind

## Target audience
Developers who drive AI coding agents (Claude Code, Cursor, Gemini). Technical,
taste-sensitive, allergic to generic SaaS marketing. They review agent-written
plans/docs as Markdown and want a fast, local, no-account tool. The landing page
must read as made-by-a-craftsperson, not generated.

## Use cases (the landing page's jobs)
1. In ~5s, understand *what Mastermind is*: a local-first Markdown reviewer where
   the file on disk is the only channel; the agent drafts a `.md`, you mark it up
   with CriticMarkup in the browser, hand it back, repeat.
2. Install fast — `npm i -g mastermind-md` (now live on npm) — the page's single
   primary action.
3. Skim the supporting proof: the review loop, the two review marks — comment +
   suggest-deletion (+ live playground), bilingual toggle, the `/mastermind` agent
   skills, local-first stance. (Review is one-directional: you flag, the agent
   rewrites — no accept/reject, no insertion/substitution, no standalone highlight.)

## Brand personality / tone
**Swiss International / Müller-Brockmann.** Rigorous 12-col modular grid, 8px
baseline, restraint. *Whimsy lives in motion and the meta-concept ("the page
reviews itself" — it presents as a Markdown doc being marked up live), never in
decoration.* Color scarcity is the discipline: paper #FCFCFA, ink #141414, muted
greys; **CriticMarkup marks are the only color allowed in the body** (insert green
#1B7A35, delete brick #A23618, highlight gold, comment blue), and **Swiss red
#E5241B is reserved for exactly one element — the Install button.** Type: Schibsted
Grotesk (display 800, tracking −0.02em) + Geist Mono (code/labels/folios).

KD's standing preference: **quiet Swiss precision over expressive chrome touches.**
Bold in structure and scale; never gaudy.

## Constraints
Astro (static) + small Preact islands in `site/`, deploy to Vercel. JS budget tight.
prefers-reduced-motion honored. Tokens live in `site/src/styles/`; design system of
record is `DESIGN.md`.
